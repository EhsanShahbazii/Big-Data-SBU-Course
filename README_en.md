## Key Features & Highlights

1. **Complete 13-Chapter Curriculum**: Covers all foundational topics from Stanford's MMDS curriculum without omitting any theoretical or algorithmic aspect.
2. **Rigorous Mathematics & Proofs**: Complete proofs for Min-Hashing Jaccard preservation, Bloom Filter false-positive rates, DGIM window stream bounds, PageRank power iteration, BALANCE algorithm competitive ratio ($1 - 1/e$), Singular Value Decomposition (SVD), Johnson-Lindenstrauss Lemma, and analytical Deep Learning backpropagation.
3. **High-Resolution Vector Graphics**: Vector TikZ diagrams for LSH pipelines, MapReduce execution graphs, Web Bow-Tie models, CURE non-spherical clusters, SVM maximum-margin hyperplanes, and multi-layer perceptrons.
4. **Clean Bidirectional Typesetting**: Formatted using XeLaTeX and `xepersian` with custom `\enparen` macros, ensuring zero reversed parentheses in bilingual prose and **0 overfull `\hbox` layout warnings** across all 81 pages.

## Build & Compilation Instructions

To build the entire course notes from source, install TeX Live (2021+) along with XeLaTeX and the `Vazirmatn` font.

1. **Compile full book**:
   ```bash
   bash scripts/compile_book.sh
   ```
   This executes $\XeLaTeX \to \text{BibTeX} \to \XeLaTeX \to \XeLaTeX$ to resolve all citations, hyperlinks, cross-references, and the table of contents.

2. **Generate standalone chapter PDFs**:
   ```bash
   python3 scripts/generate_chapter_pdfs.py
   ```
