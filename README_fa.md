## معرفی و ویژگی‌های اثر

این درسنامه جامع بر اساس نیاز دانشجویان تحصیلات تکمیلی به یک منبع خودبسنده، دقیق و آکادمیک به زبان فارسی تدوین شده است. ویژگی‌های بنیادین این اثر عبارتند از:
1. **پوشش کامل ۱۳ فصل آموزشی**: تمامی مباحث اسلایدهای درسی و کتاب مرجع MMDS بدون حذف سرفصل پیاده‌سازی شده‌اند.
2. **اثبات‌های ریاضی و فرمول‌بندی‌های تحلیلی**: قضیه Min-Hashing، تحلیل فیلتر بلوم، کران خطای الگوریتم DGIM، الگوریتم تکرار توانی در PageRank، تحلیل نسبت رقابتی الگوریتم BALANCE، تجزیه مقادیر منفرد (SVD)، لم جانسون-لیندن‌اشتراوس و پس‌انتشار خطا در شبکه‌های عصبی.
3. **نمودارهای برداری باکیفیت TikZ**: نمودارهای شفاف برای خط‌لوله LSH، گردش کار MapReduce، مدل پاپیونی گراف وب، افراز خوشه‌ها در CURE، حاشیه بهینه در SVM و معماری پرسپترون چندلایه.
4. **حروف‌چینی مدرن و سازگار با BiDi**: استفاده از ماکروی اختصاصی `\enparen` برای حل ریشه‌ای معکوس‌شدن پرانتزها در متون دوزبانه و رسیدن به **۰ خطای Overfull\hbox$** در کل ۸۱ صفحه کتاب.

## نحوه کامپایل سورس‌کد لاتک

برای کامپایل کامل کتاب، توزیع TeX Live (نسخه ۲۰۲۱ به بعد) به همراه موتور `XeLaTeX` و فونت دانشگاهی `Vazirmatn` مورد نیاز است.

اجرای کامپایل خودکار:
```bash
bash scripts/compile_book.sh
```

این اسکریپت فرآیند ۴ مرحله‌ای $\XeLaTeX \to \text{BibTeX} \to \XeLaTeX \to \XeLaTeX$ را اجرا کرده و فایل خروجی را در `BigData-Notes/main.pdf` قرار می‌دهد.

برای تولید مجدد PDFهای فصل‌به‌فصل:
```bash
python3 scripts/generate_chapter_pdfs.py
```
